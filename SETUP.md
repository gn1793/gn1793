# Profile maintenance

Edit `data/*.yaml` for profile content and `README.template.md` for section layout.
`README.md` and `assets/cards/*.svg` are generated by `scripts/build_readme.py`.
`assets/github-stats.svg` is generated by `scripts/render_stats.py`.
Keep generated images in Git: GitHub uses them to display the profile.

## Local build

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/validate_data.py
.venv/bin/python scripts/build_readme.py
.venv/bin/python -m unittest discover -s tests -v
```

Tests regenerate README, cards, and stats using local caches. Review generated
changes before committing; without a stats cache, metrics display N/A.

## Automatic updates

`.github/workflows/update-profile.yml` fetches public activity and contribution
metrics, regenerates the profile and SVG cards, and commits changes daily.
Run **Update Profile README** manually from GitHub Actions for an immediate refresh.
`.github/workflows/validate.yml` validates profile changes.

For a local data refresh, run `scripts/fetch_activity.py` and
`scripts/fetch_stats.py`, then `scripts/render_stats.py` and
`scripts/build_readme.py`. Set `GH_TOKEN` for authenticated GitHub API access.
The ignored `data/activity.json` and `data/github_stats.json` files are local caches.

## Files to keep

- `data/`: content and metadata, including the optional publications list.
- `scripts/`, `requirements.txt`: validation, fetching, and rendering.
- `assets/`: hero, rounded cards, and stats displayed on GitHub.
- `tests/`, `.github/workflows/`: checks and automatic updates.
- `README.template.md`, `README.md`: source template and generated profile.
